# integrations/ —— 成员 A 的工作区（企微接入）

这里只放**企业微信通道**相关代码，不掺业务逻辑。

## 该放什么

- 企微机器人 SDK 的接入与回调处理
- 消息去重（`wecom_msg_id`）与身份注入
- 私聊消息 → `agent/` 的入口适配
- 主动推送（P1，最后做）

## 配置

凭据只放 `.env`（已被 `.gitignore` 忽略），样例见根目录 `.env.example`：

```
WECOM_BOT_ID=
WECOM_BOT_SECRET=
```

**不要把真实凭据提交到仓库**，也不要把它们写进 `docs/` 或演示视频。

## 接入顺序（V4 第 3.2 节）

1. 确认有可用的企微组织、机器人、测试成员
2. 先做固定回复：手机私聊「你好」→ 回「收到」（不接模型、不接数据库）
3. 再接「发一下计划表」返回测试看板链接，手机点开验证
4. 最后接通知处理、身份、去重

⚠️ 第 2 步没跑通之前，不要写业务代码。

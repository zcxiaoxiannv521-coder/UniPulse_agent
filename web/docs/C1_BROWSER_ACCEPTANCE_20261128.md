## 本轮修正与复测

| 问题 | 修正 | 复测结果 |
|---|---|---|
| 表单提交失败的错误可能被收起的表单遮住 | 保存操作失败后，将中文错误统一显示在页面上方 | 重新提交冲突课程，错误无需展开表单即可看到；修正输入后可正常保存且旧错误不残留 |
| 共享后端模式仍写“新增课程后计划会标为待检查”，与本次实际结果不符 | 两种模式分别提示；共享模式明确以后端返回状态为准 | 浏览器显示新提示；未擅自修改 B 的计划状态逻辑 |
| 下拉菜单的关闭提示和“可用选项/已选择”无障碍提示仍有英文 | 补充这些框架文案的中文转换 | 实际展开菜单显示“有 3 个可选项”“关闭菜单”和“已选择” |

新增一项失败输入修正后的回归测试：失败不写入数据，随后改正时间可以保存、错误消失，首页显示新课程。完整回归结果为 **296 项通过，另有 7 项子检查通过**；1 条第三方 TestClient 弃用提示不阻断。

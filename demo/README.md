## 怎么用

```bash
# 1. 先建表
python -m database.connection

# 2. 写入演示数据（可重复执行，不会重复插入）
python -m demo.seed

# 3. 打开演示时间模式（另开终端执行，或写进 .env）
export UNIPULSE_TIME_MODE=demo
export UNIPULSE_DEMO_NOW=2026-11-30T09:00:00+08:00
```

只想重来一次（会丢弃对演示数据的修改）：

```bash
python -m demo.seed --reset
```

## 数据规则

- 所有 ID 固定（`us_demo_a` / `ex_demo_ml_final` …），重复执行不会重复插入
- 重复执行**不会覆盖**你手工改过的行（用的是 `INSERT OR IGNORE`）
- 整个写入在一个事务里，中途出错全部回滚
- 课程名、老师名都是虚构的，不出现真实班级信息
